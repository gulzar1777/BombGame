# Bomba və pişik

C# və Windows Forms ilə hazırlanmış sadə oyun. Altı qutudan beşində pişik, birində bomba var.

- Pişik tapıldıqda xal 1 artır. Eyni qutu ikinci dəfə xal vermir.
- Bomba açıldıqda partlayış səsi səslənir və oyun bitir.
- Beş pişik tapıldıqda qələbə bildirişi göstərilir. OK düyməsindən sonra yeni oyun başlayır.
- Yeni oyun zamanı xal sıfırlanır və bomba əvvəlkindən fərqli qutuya yerləşdirilir.
- Çıxış düyməsi proqramı bağlayır.

## Açmaq

Windows-da Visual Studio ilə `BombaOyunu.sln` faylını açın və F5 basın. Visual Studio-da **.NET desktop development** və **.NET Framework 4.8 targeting pack** quraşdırılmış olmalıdır.

Şəkillər və səs layihəyə daxildir, əlavə paket tələb olunmur. Windows Forms macOS-da işləmir.

ZIP-i çıxarın və `BombaOyunu` qovluğunun içindəki bütün faylları və alt qovluqları repozitoriyaya yükləyin. `.sln` faylı repozitoriyanın əsas qovluğunda olmalıdır.
